Mẹo chọn nhanh

Dùng Go Webview (webview_go) khi:

Bạn đã có sẵn dự án web viết bằng Go (Gin, Fiber, Echo) chạy SSR và muốn đóng gói siêu tốc, file cài chỉ cần 10-15MB.

Dùng Wails khi:

Bạn muốn làm một ứng dụng Desktop chuyên nghiệp, viết mới giao diện bằng React/Vue/Vite và muốn Go xử lý logic ở tầng hệ thống mượt mà.

Dùng Lorca khi:

Bạn ngại sự bất ổn định của hệ thống WebView trên Windows cũ và muốn mượn sức mạnh đồng nhất của Google Chrome có sẵn trên máy người dùng.

Điểm cốt lõi:

Ứng dụng thực chất chạy một Web Server siêu nhỏ bên trong máy người dùng một cách an toàn (chỉ mở kết nối nội bộ Loopback 127.0.0.1). WebView đóng vai trò như một chiếc "gương" giúp loại bỏ thanh địa chỉ của trình duyệt, tạo cảm giác đó là một phần mềm Native Desktop hoàn chỉnh.

Bảng Ma Trận So Sánh Các Giải Pháp

Các chỉ số được đo lường dựa trên việc đóng gói ứng dụng Go kết hợp UI Web

Giải pháp Dung lượng File (.exe/.app) Mức tiêu thụ RAM Độ đồng nhất UI trên các OS Mức độ can thiệp Hệ thống (Native API) Phù hợp nhất cho
webview_go
~ 10 MB - 15 MB Rất thấp (~ 30-50MB) Trung bình (Phụ thuộc OS) Thấp (Cần tự viết CGO) Tool nội bộ, Server SSR có sẵn cần giao diện nhanh.
Wails (v2/v3)
~ 15 MB - 25 MB Thấp (~ 50-80MB) Khá tốt (Đã tối ưu sâu) Rất mạnh (Có sẵn Bridge Go-JS) Phần mềm thương mại hiện đại sử dụng React/Vue/Vite.
Lorca
~ 8 MB - 12 MB Trung bình (Dựa trên Chrome) Tuyệt đối (Chạy lõi Chrome) Thấp App nội bộ, yêu cầu giao diện phức tạp nhưng đồng nhất.
Tauri (Rust)
~ 10 MB - 20 MB Rất thấp (~ 40-70MB) Rất tốt Rất mạnh Thay thế Electron nếu bạn thạo thêm Rust ở Backend.
Electron (JS)
> 120 MB Rất cao (> 150MB - 300MB) Tuyệt đối (Bao gồm Chromium) Toàn diện nhất App doanh nghiệp lớn như VS Code, Slack, Discord.
webview_go (SSR tối giản) 
package main

import (
	"embed"
	"html/template"
	"net"
	"net/http"
	"github.com/webview/webview_go"
)

//go:embed templates/*
var templatesFS embed.FS

func main() {
	// 1. Tự động lấy một Port trống ngẫu nhiên
	listener, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		panic(err)
	}
	port := listener.Addr().(*net.TCPAddr).Port

	// 2. Chạy Server SSR (Gin, Fiber hoặc Standard HTTP)
	tmpl := template.Must(template.ParseFS(templatesFS, "templates/*.html"))
	http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
		tmpl.ExecuteTemplate(w, "index.html", map[string]interface{}{
			"Title": "Chào mừng bạn tới Go SSR Desktop!",
		})
	})

	go http.Serve(listener, nil)

	// 3. Khởi động WebView hiển thị Server đó lên Desktop
	w := webview.New(false)
	defer w.Destroy()
	w.SetTitle("Go SSR Desktop App")
	w.SetSize(1024, 768, webview.HintNone)
	w.Navigate(http.Sprintf("http://127.0.0.1:%d", port))
	w.Run()
}
Wails v2/v3 (Khuyên Dùng) 
// Cài đặt công cụ wails:
// go install github.com/wailsapp/wails/v2/cmd/wails@latest
// Khởi tạo: wails init -n my-app -t svelte

package main

import (
	"embed"
	"github.com/wailsapp/wails/v2"
	"github.com/wailsapp/wails/v2/pkg/options"
	"github.com/wailsapp/wails/v2/pkg/options/assetserver"
)

//go:embed all:frontend/dist
var assets embed.FS

func main() {
	app := NewApp() // Tạo struct App chứa logic xử lý

	err := wails.Run(&options.App{
		Title:  "Ứng dụng Wails Pro",
		Width:  1024,
		Height: 768,
		AssetServer: &assetserver.Options{
			Assets: assets, // Wails quản lý asset tuyệt đối không cần server ngầm
		},
		Bind: []interface{}{
			app, // Bind các hàm Go cho Javascript gọi trực tiếp
		},
	})

	if err != nil {
		println("Error:", err.Error())
	}
}
